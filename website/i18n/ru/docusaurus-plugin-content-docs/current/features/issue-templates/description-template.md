# Шаблон описания

| | |
|---|---|
| Где настраивается | Диалог создания задачи / подзадачи (кнопки рядом с Description) |
| Где видно | Диалог создания задачи / подзадачи |
| Настройки действуют | Только для вас |

## Цель

Ускорить заполнение поля **Description** при создании задачи или подзадачи: вставить готовую структуру и сохранить свой текст как шаблон на следующий раз.

## Как настроить

### Где найти настройки

Отдельного экрана настроек нет. Откройте **Create** (задача или подзадача) как обычно — кнопки появляются рядом с полем описания.

### Как настроить

- **«Add template»**: нажмите кнопку (иконка пера), чтобы вставить структурированный шаблон в описание. Пока вы не сохраните свой, используется встроенный bug-style каркас.
- **«Save template»**: отредактируйте описание и нажмите кнопку сохранения (иконка дискеты), чтобы сохранить текущий plain-text как личный шаблон в этом браузере.

## Как использовать

- Когда в диалоге создания задачи или подзадачи видно поле описания, рядом появляются две кнопки.
- Нажмите **«Add template»**, чтобы вставить сохранённый (или встроенный) текст.
- После закрытия и повторного открытия диалога кнопки работают так же.

## Сценарии использования

- **Баг-репорты:** Держите готовый каркас Structure / Steps / Expected / Actual для каждого нового бага.
- **Повторяемые формы создания:** Сохраните чеклист под проект, чтобы каждая новая задача начиналась с одних и тех же секций.

## Устранение неполадок

- **Кнопок нет:** Дождитесь полной загрузки диалога и появления поля описания. Перезагрузите страницу, если диалог оставался открытым после обновления UI Jira.
- **Шаблон пропал:** Шаблон хранится в local storage браузера. Очистка данных расширения/сайта удаляет его — сохраните описание заново.
