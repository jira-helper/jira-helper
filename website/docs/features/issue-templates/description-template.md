# Description Template

| | |
|---|---|
| Where configured | Create Issue / Create Sub-task dialog (buttons next to Description) |
| Where visible | Create Issue / Create Sub-task dialog |
| Settings apply to | Only for you |

## Purpose

Speed up filling the **Description** field when creating an issue or sub-task by inserting a ready-made outline and saving your own text as the template for next time.

## How to configure

### Where to find settings

There is no separate settings screen. Open **Create** (issue or sub-task) as usual — the buttons appear next to the description field.

### How to configure

- **Add template**: click **«Add template»** (pen icon) to paste the structured template into the description. A built-in bug-style outline is provided until you save your own.
- **Save template**: edit the description, then click **«Save template»** (save icon) to store the current plain-text description as your personal template in this browser.

## How to use

- Whenever the create-issue or create-sub-task dialog shows a description area, the two buttons appear beside it.
- Click **«Add template»** to insert the saved (or built-in) text.
- After closing and reopening the dialog, the buttons work the same way.

## Usage scenarios

- **Bug reports:** Keep a standard Structure / Steps / Expected / Actual outline ready for every new bug.
- **Recurring create forms:** Save a project-specific checklist so every new issue starts with the same sections.

## Troubleshooting

- **Buttons missing:** Ensure the create dialog is fully loaded and the description field is visible. Reload the page if the dialog was left open across a Jira UI update.
- **Template lost:** The template is stored in browser local storage. Clearing extension/site data removes it — re-save after composing the description again.
